# Reference board (12 games)

| Game | Steal for Swipe |
|---|---|
| [Balatro](https://store.steampowered.com/app/2379780/) | Loot card hover tilt; ATK/BLK numbers pop and count up. |
| [Luck be a Landlord](https://store.steampowered.com/app/1404850/) | Wheel landing: each monster's effect pulses in order. |
| [Slay the Spire](https://store.steampowered.com/app/646570/) | Monster ATK/HP badges as intents; keyword tooltips in inspect. |
| [Peglin](https://store.steampowered.com/app/1296610/) | Pick panel beside the board, never over it. |
| [Dicey Dungeons](https://store.steampowered.com/app/861540/) | Loot cards with one huge number; monsters with attitude. |
| [Loop Hero](https://store.steampowered.com/app/1282730/) | Board stays visible during the draft; dark ground, lit tiles. |
| [Cult of the Lamb](https://store.steampowered.com/app/1313140/) | Cute-sinister tone; stamp-style tier plates. |
| [Inscryption](https://store.steampowered.com/app/1092790/) | Monster reveal: silhouette, then slam. |
| [Into the Breach](https://store.steampowered.com/app/590380/) | Show the risk (Weak/Tough/Deadly) before Take. |
| [Backpack Hero](https://store.steampowered.com/app/1970580/) | Metal rims on every icon; pickup squash and sparkle. |
| [Ring of Pain](https://store.steampowered.com/app/998740/) | Ring-of-cards dungeon around the player, the closest analog to the Swipe wheel. |

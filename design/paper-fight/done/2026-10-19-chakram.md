# Paper Fight — Chakram

**Status:** Answers in. Shipped 2026-10-19.

**Pitch (Nathan’s words):** New Item, Tier 2, Chakram. Block 3 if you have no Items that Block. Atk 3 if you have no Items that Attack. Checks for items in inventory that do either. Marble counts (for both at once), making it bad for this. Double Buckler does not (it doesn't actually gain block). Values of 0 count (the item blocks, even if it would block for 0). Can be used such that only one half of the card can be used. Unplayable if neither condition is met (if I have at least 1 other card that blocks and 1 other card that attacks).

**Restate (what the player does):** During a fight they click Chakram. The card is used up. They do not pick a target. At click, the game looks at the other items currently in the hotbar:

- If none of those items Grant Block, they Gain 3 Block (same click as Shield).
- If none of those items deal Attack, they deal 3 Attack to the facing enemy (same click as Arrow Head).
- Both can happen on the same click.
- Only one half can happen (they still click once; the dead half does nothing; the card is still used up).
- If both halves are dead, the card is grey with the unplayable hatch and the click does nothing.

Chakram does not count itself. Marble sitting in the hotbar counts as both, even at 0, even before it has been clicked. Double Buckler does not count as Block. Medallion / Spiked Shield / Mirror Shard at 0 still count as Block.

**Where it happens in a round:** Only while fighting. Click the card, no second click. Used up. Numbers are printed 3s, not a copy of something else. Block sits until a hit spends it, same as Shield. Attack happens now, not on Done.

---

**Which existing cards this touches:**

- **Marble** — counts as Block and as Attack at once, including at 0, including undeclared. One Marble turns both halves off, so Chakram is unplayable. Bag of Marbles itself is neither; after it fills, the Marbles brick Chakram.
- **Double Buckler** — does not Grant Block. Does not deal Attack. Holding it does not turn either half off.
- **Shield / Helmet / Medallion / Left Bracer / Right Bracer / Breastplate / Stone Wall / Grief Jar / Lucky Nickel / Mirror Shard / Spiked Shield** — Grant Block. Any one of these in the hotbar turns the Block half off, including Medallion at full HP (0) and Spiked Shield with no Attack item (0).
- **Throwing Knife / Sai / Crossbow / Longbow / Great Axe / Arrow Head / Shuriken / Knucklers / Spiked Flail / Bloody Gauntlets / Grimoire / Chain / Counting Beads** — deal Attack. Any one turns the Attack half off.
- **Last Match** — unplayable while any Attack item is in hand. Unplayed Chakram is not an Attack item for Last Match or Spiked Shield.
- **Net / Caltrops** — change the enemy’s Attack. They do not deal Attack and do not Grant Block.
- **The Boot / Sledgehammer / Measuring Tape / Fangs / Paci Fist / Catapult** — Defeat / Eject, not Attack, not Block.
- **Healing Potion / Hex / Toll / Smoke Bomb / poison / Napalm / flasks / Pacemaker** — neither.
- **Spider Egg** — deals 2 to you. Does not count.
- **Echo Bell** — counts as whatever it copied, unless it copied Chakram (ignored like other Chakrams).
- **Hornet Swarm / Queen / Damsel / Kobold / Shambling Mound** — extra swings spend Block on the first swing. Chakram’s Attack is a click now.
- **Dragon / Arrow Head pierce** — Block 3 does not stop pierce. Attack 3 still hits.
- **Goblin** — Attack half deals 0. Block half still Grants 3.
- **Anvil** — Attack 3 becomes 1.
- **Needleback** — Attack 3 is a hit, so you take 2.
- **Eel** — Gain 3 Block chips Eel for 3 Attack damage.
- **Bushido** — second item this fight does nothing. Dummy-silenced items do not count for the check.
- **Basilisk petrify** — petrified items do not count.
- **Tutorial kit / Developer Test** — tutorial often has Shield and Knife together, so Chakram would be unplayable in that hand.

**Generous reading:** Check the live hotbar at the moment of the click, skip Chakram copies, skip petrified items. Spend Shield this fight and the Block half turns on. Two Chakrams and nothing else that Blocks or Attacks: both fully on.

**Stingy reading:** Snapshot the hotbar at the start of the fight. Two copies make each other unplayable. Petrified Shield still counts.

**Ways it can fail (crash, stuck game, card text that does not match the hit):**
- Chakram counts itself, so both halves are always dead.
- Two copies count each other and both sit grey.
- Marble at 0 is ignored.
- Double Buckler is treated as Block.
- Medallion at 0 or Spiked Shield at 0 is ignored.
- Unplayable hatch never appears.

**What the player sees:** A T2 item. Grey hatch only when both halves are dead. One click: maybe Block, maybe a 3 hit, maybe both, then the card is gone. With a Marble in hand it stays grey. With only Shield in hand, clicking it hits 3 and does not Grant Block.

**If we skip this:** Shield already Grants Block. Arrow Head already deals 3 Attack.

**If we take the strongest reading:** Opening hand of Chakram plus heals / Defeat / Smoke: one click is Block 3 and Attack 3. Spend Shield first, then Chakram also Grants Block 3. Two copies are Block 6 and Attack 6.

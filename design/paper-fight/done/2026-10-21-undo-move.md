# Paper Fight — Undo a Move

**Pitch (Nathan’s words):** The user should be able to undo any movement using the same undo and redo buttons.

**Restate (what the player does):** In Adventure, while you are fighting, you click the left or right Move control. You walk to a living neighbor, spend one of your three Moves, and now you are facing that owner. Undo should put you back on the previous owner and give that Move back. Redo should walk you there again. Same Undo / Redo buttons as item uses.

**Where it happens in a round:** Only while you are fighting in Adventure, before Take or Spin. You click a Move control. The spent Move is a counter (3 → 2 → 1 → 0).

**Which existing cards this touches:**
- Skeleton (HP Echo) — snapshot includes `last_mob_hp`
- Wraith — plate ATK restores from the wheel snapshot
- Commander / Lich — `spin_locked` restores with the wheel
- Goblin, Hornet, Queen, Dragon, Mimic, Slime — no hit on Move
- Empty alcove — Move already skips
- Tutorial — Undo disabled; Moves are Adventure-only
- Take / Spin — still wall the stack

**Generous reading (picked):** A Move is one Undo step, same as using an item. Take and Spin still wipe the stack.

**Stingy reading:** Undo only the most recent Move, and only if no item was used after.

**Nathan’s pick (2026-10-21):** like an item. Take/Spin still wipe.

**What shipped:** `_try_move` calls `_undo_begin` / `_undo_commit` instead of `_undo_wall`. Restore snaps the wheel to the faced seat.

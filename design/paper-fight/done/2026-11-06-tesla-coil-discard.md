# Paper Fight — Tesla Coil discards on a successful auto Defeat

**Pitch (Nathan’s words):** Tesla Coil should be discarded when it successfully defeats an enemy, with a loud animation so the player understands it was automatically triggered (much like how Hex works).

**Answers:**
- Discard as soon as the Charge check hits, even if Commander, Petty King, Triclops, or Phoenix then rewrites the Defeat. Same spend timing as Hex.
- If more than one coil could beat that HP, only the lowest Charge that still beats them fires. One card.
- Ability, Shift, and Flow overridden. Added “Then Discard this.”

**What shipped:** The name banner plays, the card flies off the hotbar (slow toss, Hex’s use sound), then the Defeat runs. Clicking it to Flee still keeps it and adds 1 Charge. A petrified coil does not fire. If Lich survives the chip, the coil is already gone and the fight continues.

# Paper Fight — Hydra Hungry Heads (#341)

**Pitch (Nathan’s words):** Hydra rework: same trigger (other monster falls to 3 or less hp), but now reads: "...I Defeat them, Gain their HP, and gain an additional attack." Additional attacks work just like Hornet Swarm. Buff Hydra's starting attack to 3, rename ability to 'Hungry Heads'

**Restate (what the player does):** They never click Hydra. After an item or Spin, if another monster dropped to 3 HP or less and is still alive, Hydra Defeats that monster, adds that monster's remaining HP to Hydra, and gains one extra Take swing (Hornet-style). Printed Attack stays 3.

**Where it happens in a round:** after the current action, automatic, not used up, number of extra swings keeps growing.

**Which existing cards this touches:**
- Hornet Swarm (extra swings, Block on first swing)
- Napalm / Boot / Needleback (HP drop to 3 or less)
- Commander / Petty King / Phoenix / Lich (stay after a Defeat attempt)
- Quiet Bell
- Shambling Mound extra-swing loop (separate)

**Generous reading:** Add the meal's remaining HP. +1 extra swing per meal, stacking. Attack stays 3.

**Stingy reading:** Set Hydra HP equal to the meal instead of adding. Extra swing only while facing that fight.

**Ways it can fail:**
- Infinite loop if Hydra meals Hydra
- Extra swings after Hydra dies
- Text still saying +2 Attack

**What the player sees:** Slash, meal dies, hearts fly onto Hydra, extra Take swings like Hornet.

**If we skip this:** Old Devour +2 Attack.

**If we take the strongest reading:** Generous: add HP, stack extra swings forever this dungeon.

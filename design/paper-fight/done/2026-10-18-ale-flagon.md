# Paper Fight — Ale Flagon

**Nathan’s picks:**
1. If this Spin already finished the last monster, skip the player’s poison tick (you win).
2. Healing Potion still saves a 0 from poison. Poison is already gone.
3. New dungeon wipes leftover player poison.

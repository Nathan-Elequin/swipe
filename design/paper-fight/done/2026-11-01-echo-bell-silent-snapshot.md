# Echo Bell — silenced snapshot of last play

**Pitch (Nathan’s words):** When Echo Bell copies the most recently played item, it is an exact copy of whatever that item was when it was played. Scaling items show the final value displayed at play (eg 8 atk). Copied items have passives turned off (Ball & Chain, Grief Jar −1 HP, Cursed Scroll −1 HP). Echo itself does not scale.

**Restate (what the player does):** Click Echo Bell. It plays the number that was on the last used item at the moment of that use, then Echo is used up. It does not keep ticking or growing.

**Where it happens in a round:** Fight click. Used up. Target click only if the original needed one. Number copied once.

**Which existing cards this touches:**
- Spiked Flail / Grief Jar (scaling)
- Ball & Chain (no-Flee while in hand)
- Cursed Scroll / Grief Jar (Spin HP loss)
- Dual Sai / Shield flip (in-hand flip)
- Lantern (heal_keep increment)

**Generous reading:** Bake the shown number into a plain Attack / Block / Heal; skip in-hand passives on Echo.

**Stingy reading:** Live-link to the original card so later Spins still change Echo’s number.

**Ways it can fail:** Echo of Echo; Keep on original; targeting items.

**What the player sees:** Echo looks like the last item, with the number from that play, faint Echo mark.

**If we skip this:** Echo keeps live-linking.

**If we take the strongest reading:** One click can replay a huge scaled Flail/Jar without the downsides.

# 12_GEMINI_mon_dragon

**1. Open:** https://gemini.google.com/app

**2. Prompt** (copy all of it):

```
Style: crisp retro pixel art like a 16-bit SNES/GBA game for the dark-fantasy dungeon game "Spinheritance". Every art pixel is a hard-edged square of one flat colour on one consistent grid. 1-pixel near-black outline (#100e0c) on characters and objects. 3-4 tone colour ramps, light from the upper-left. No anti-aliasing, no blur, no gradients, no soft glow, no dithering noise, no painterly or 3D look. Gold is #FFD84A. Stay inside the colours of the palette image. Never draw any text, letters, numbers or watermarks.

Sprite sheet: one horizontal strip of 4 equal square cells, each 64x64 art pixels, shown large with crisp square pixels. The monster is the dragon in image 1, redrawn bigger and more expressive (a new drawing, not a recolour) but with the same design and colours: red-orange dragon, cream belly, horned head, wings. Side view facing RIGHT, chasing something greedily. A 4-frame looping run cycle: low lunging run, wings half open and flapping. Big readable face with attitude: furious, smoke curling from the nostrils, jaws open. Same size and same position in every cell; the lowest point touches the very bottom row of each cell, no empty rows below, no ground shadow. Flat solid magenta #FF00FF background, no grid lines, no text. Use image 2 as the colour palette.
```

**3. Attach:** Select all images in this folder (2) and drop them into the chat.

**4. Save the result as:** `..\returns\mon_dragon_raw.png`

**5. If it's off** (paste in the same chat, one at a time):
- `Keep everything, but turn it to face right.`
- `Keep everything, but make all 4 frames the same size with the lowest point on the bottom edge.`
- `Make the face bigger and more expressive.`

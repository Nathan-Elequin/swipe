# 07_GEMINI_mon_dire_wolf

New design. Don't use the old wolf sprite.

**1. Open:** https://gemini.google.com/app

**2. Prompt** (copy all of it):

```
Style: crisp retro pixel art like a 16-bit SNES/GBA game for the dark-fantasy dungeon game "Spinheritance". Every art pixel is a hard-edged square of one flat colour on one consistent grid. 1-pixel near-black outline (#100e0c). 3-4 tone colour ramps, light from the upper-left. No anti-aliasing, no blur, no gradients, no soft glow, no dithering noise, no painterly or 3D look. Never draw any text, letters, numbers or watermarks.

Match the art style, outline weight, shading and level of detail of the goblin in image 1 exactly, so this monster looks like it belongs in the same game. Use only the colours in image 2.

Sprite sheet: one horizontal strip of 4 equal square cells, each cell 32x32 art pixels, shown large with crisp square pixels. A brand-new design: a dungeon DIRE WOLF, menacing but fun. A big shaggy wolf with a huge head, an oversized toothy grin and drool, glowing yellow eyes, a scarred ear, a spiky ruff of dark grey-blue fur with a lighter belly and muzzle, heavy paws with claws, and a rusty iron collar with a broken chain link trailing behind. Greedy and excited, like a dog chasing a thrown treat. Side view facing RIGHT, running toward the right edge.

4-frame looping gallop: frame 1 front legs reaching forward and back legs stretched behind; frame 2 all four legs bunched under the body, back arched highest; frame 3 back legs pushing off, front paws landing; frame 4 legs gathering again, body lowest. The tongue and chain swing one frame behind the body. Same size and position in every cell; the lowest paw touches the very bottom row of each cell, no empty rows below, no ground shadow. Flat solid magenta #FF00FF background, no grid lines, no text.
```

**3. Attach:** Select all images in this folder (2) and drop them into the chat.

**4. Save the result as:** `..\returns\mon_dire_wolf_raw.png`

**5. If it's off** (paste in the same chat, one at a time):

- `Bolder and simpler: bigger head and teeth, fewer fur details, so it reads at 32x32 pixels.`
- `Make it look more like true pixel art: bigger, flatter square pixels, no blur.`

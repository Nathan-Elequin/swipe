# 05_GEMINI_nib_lantern

**1. Open:** https://gemini.google.com/app

**2. Prompt** (copy all of it):

```
Style: crisp retro pixel art like a 16-bit SNES/GBA game for the dark-fantasy dungeon game "Spinheritance". Every art pixel is a hard-edged square of one flat colour on one consistent grid. 1-pixel near-black outline (#100e0c) on characters and objects. 3-4 tone colour ramps, light from the upper-left. No anti-aliasing, no blur, no gradients, no soft glow, no dithering noise, no painterly or 3D look. Gold is #FFD84A. Stay inside the colours of the palette image. Never draw any text, letters, numbers or watermarks.

Sprite sheet: one horizontal strip of 2 equal square cells, each 32x32 art pixels, crisp square pixels. The character is Nib from image 1: a small blue imp with pointed ears, a pointed tail and a mustard-yellow coat. Nib stands planted, facing RIGHT, holding up a small black iron lantern with a warm yellow flame, the same lantern as in image 1. The 2 frames are an idle loop: in frame 2 the flame is a little taller and brighter and the tail flicks; otherwise identical. Same size and same position in every cell; the lowest point touches the very bottom row of each cell, no empty rows below, no ground shadow. Flat solid magenta #FF00FF background, no grid lines, no text. Use image 2 as the colour palette.
```

**3. Attach:** Select all images in this folder (2) and drop them into the chat.

**4. Save the result as:** `..\returns\nib_lantern_raw.png`

**5. If it's off** (paste in the same chat, one at a time):
- `Keep everything, but make Nib match image 1 exactly (blue skin, mustard coat).`
- `Keep everything, but make both frames the same size with the feet on the bottom edge.`

Fallback: ChatGPT Images (https://chatgpt.com), same prompt and images.

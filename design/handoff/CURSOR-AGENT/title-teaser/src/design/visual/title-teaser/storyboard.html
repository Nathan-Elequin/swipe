2. Grab · 2–5s

Camera: side-scroll. Art: hall strip or tiled hall. Reuse: live item 16×16, monster sheets.
  • Halls scroll. Grandpa’s items float ahead.
  • Hero catches some, misses some.
  • Monsters enter from behind.

3. Spend to keep · 5–8.5s

Camera: still tracking, chase tightens. Hero: swipe / block. Used sprite is gone.
  • Hero uses Boot / Block / potion-class into a monster so he can keep running with the rest.
  • That item disappears. Remaining loot clings to him.
  • Halls change. More monsters.

4. Swirl · 8.5–11s

Camera stops tracking. Hero to center. Remaining loot, monsters, hall fragments orbit. Bloom from the items he still holds.
  • This is the greedy escape tightening into a title card, not a fight UI.

5. Whiteout → still · 11s then hold

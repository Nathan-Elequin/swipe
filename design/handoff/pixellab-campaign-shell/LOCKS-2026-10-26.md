## Map interaction
- Opening the map is **Sprout POV holding the map in hands** — not a zoom that stays in cabin.
- Toggle: **Spacebar** for now (M / Esc later).
- Five biomes connected by **drawn navigator lines**.
- Obvious **start node** for a normal run from B1.

- After a biome hits 5/5, Nib **pencils the path** and **stamps** the next biome (custom biome seal + name). Stamp is clickable; hover = slight peel lift.
- **Endless** = sixth option on the wall map (locked until all five cabinets clear).

## Cabinets (vertical stacks)
- One **visually separate, biome-themed case** per pool (vines/moss for swamp, etc.).
- Items mount in **collection order** (no fixed slot ownership).
- Uncollected silhouettes placed somewhat randomly in remaining space.
- Item states: **unseen** / **seen-not-collected** (silhouette) / **collected** (glowing trophy mount).
- Threshold: **5 collected in that pool** unlocks narrative progress (next map path/stamp). Player can keep filling the rest of the pool toward 100% completion endgame.
- Banking = that biome's pool. Multi-biome runs can fill **multiple cabinets** in one return animation.

# Offline mechanics index

Stored so a later chat can search this folder instead of the web.

## Welcome to the Dungeon (Iello / Phantom)

Monsters (strength order, typical): Goblin, Skeleton, Orc, Vampire, Golem, Lich, Demon, Dragon.  
Equipment that is not “a sword”: Vorpal Blade, Polymorph, Invisibility Potion, Ring of Power, Shield, Torch, Grappling Hook, Holy Grail, Mage’s Staff, Dragon Spear, Plate Armor, Mirror Shield, Tome, Gelatinous Cube (monster that eats equipment), Mimic, Shapeshifter.

Core: one player is the adventurer; everyone else loaded the dungeon. You succeed by surviving the stacked taxes. Success/fail is binary.

## Munchkin

Slots (head, armor, foot, hands). One-shots. Curses. Level + combat bonus. “This monster is +N against [class].” Wandering Monster. “Sell items for levels.” Humorous named loot (Really Impressive Title, Sneaky Bastard Sword). Most of that does not map onto Swipe.

## One Deck Dungeon

Dice. Skills cost time. Monster overlays: Drain, Fade, Frost, Split, Undying, Poison. Relics that change a skill. Time track as HP.

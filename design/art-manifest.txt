# Swipe art manifest - batch 1 (art bible), 2 (item icons), 3 (monsters + Nib), 4 (hall tiles/props + hearts), 5 (UI chrome), 6 (VFX), 7 (HUD glyph SVGs + icon.svg), style 'Crypt Classic'
# Original hand-authored pixel maps (Python/PIL char maps). No AI generation, no pack art (0x72/Kenney/Lucide/etc.).
# Item PNGs: authored 16x16, shipped 4x nearest-neighbour, RGBA, transparent, 1px #100e0c outline, no text.
# Monster PNGs: authored small 16x16 / standard 16x28 / large 32x36, shipped 4x (64x64 / 64x112 / 128x144), feet on the bottom row,
#   coloured by family, plain (no tier trim, no glow - Weak/Tough/Deadly glow is a Godot shader). Static frame 0 only; idle ideas in design/idle-animation-notes.md.
# Hall tiles: authored 16x16 (column 16x48, crate 16x24), shipped 4x as separate PNGs named after the atlas slice (tile_list.txt) for re-atlasing;
#   hearts ship at their exact 13x12 slice size. Floors have mortar on the bottom row + right column so all 8 variants tile on a 16 grid.
# UI chrome: authored AT ship size (exact Kenney-slot dimensions) on a 2px grain; 9-slice margins listed per file (L T R B, px); the stretch
#   rows/columns are verified flat by build45.py (review/nine_slice_check.txt). Cursors authored half size, 2x nearest, hotspot top-left.
# VFX: authored 64x64 (4 flat white/grey tones, stepped alpha, no outline, no dithering), shipped 4x = 256x256 under the brief's {key}.png names.
# SVG glyphs: 12x12 pixel cells x 2 units on the 24x24 viewBox, one single-colour <path> each (brief colours), shape-rendering crispEdges.
# Rebuild: python3 gen/build.py (generator kept outside the repo at /workspace/swipe-assets/gen).
#

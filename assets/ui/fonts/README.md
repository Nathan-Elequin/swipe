# Title-framed fonts (OFL)

Shipped for the framed title hub (design B).

| Family | Files used in-game | Licence |
|---|---|---|
| EB Garamond | `eb_garamond/EBGaramond-SemiBold.ttf` (weight 600 title) | SIL Open Font Licence 1.1 — see `eb_garamond/OFL.txt` |
| Open Sans | `open_sans/OpenSans-SemiBold.ttf` (actions), `OpenSans-Regular.ttf` (helpers / Feedback) | SIL Open Font Licence 1.1 — see `open_sans/OFL.txt` |

Sources:
- Static Latin instances: Fontsource CDN redistributions of the Google Fonts OFL packages (`@fontsource/eb-garamond` / `@fontsource/open-sans` 5.2.5).
- Variable masters + OFL text: [google/fonts](https://github.com/google/fonts) `ofl/ebgaramond` and `ofl/opensans`.
- Upstream projects: [EBGaramond12](https://github.com/octaviopardo/EBGaramond12), [Open Sans](https://github.com/googlefonts/opensans).

Do not substitute system/default fonts for the title hub without updating `design/visual/SCREEN-title-framed.md`.
